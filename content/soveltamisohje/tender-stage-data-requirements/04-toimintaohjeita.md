**Numbering**

The identification and recognition of element types described in this guideline does not affect the numbering of execution-stage elements or the naming of drawings used in projects. Numbering can be agreed per project, taking into account, among other things, the numbering features of Tekla Structures. If the method described in the guideline on unique product identification and data carrier interoperability is used to identify elements at the execution stage, there is no need to use the ACN number.

**Location data**

A separate guideline covers block and floor data.

**Revision practices**

Revision and data exchange using Peppol messages at the execution stage will be specified later.
