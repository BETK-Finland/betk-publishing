The reinforcement type of the element type is selected in the reinforcement data field, with a more detailed description in the description field. For example R1 and `2T10 ymp`, or R2 and `2T10 ymp, #10-200 mp` (*ymp* = around the perimeter, *mp* = both faces). If necessary, the reinforcement codes used in the project can be specified in a separate document delivered with the model. Example tables of reinforcement data at the tender stage are given at the end of this guideline.
