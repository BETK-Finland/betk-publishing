Yksikkökoodeissa käytetään UN/ECE Recommendation 20 -koodistoa (mukaan lukien X-etuliitteiset Recommendation 21 -koodit). Seuraavaa lyhyttä listaa suositellaan betonielementtien toimitusketjuun. Mahdollisissa laajennuksissa tarkastellaan ensisijaisesti SFTI:n lyhyttä listaa (liite D).

| `cbc:Quantity/@unitCode` | Kuvaus (EN) | Kuvaus (FI) | Kuvaus (SV) | Huomiot |
|---|---|---|---|---|
| `C62` | one | kappale | styck | Käytä koodia `EA` `C62`:n sijaan sanomia muodostettaessa. `C62` tulee ymmärtää sanomia vastaanotettaessa. |
| `H87` | piece | kappale | styck | Käytä `EA` sanomia muodostettaessa; `H87` tulee ymmärtää vastaanotettaessa. |
| `EA` | each | kappale | styck | Ensisijainen koodi sanomia muodostettaessa. |
| `KGM` | kilogram | kilogramma | kilogram | |
| `MTK` | square metre | neliömetri | kvadratmeter | |
| `MTQ` | cubic metre | kuutiometri | kubikmeter | |
| `MTR` | metre | metri | meter | |
